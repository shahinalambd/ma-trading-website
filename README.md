# M.A Trading & Services Website

A bold, industrial website concept for a scrap buying, dismantling and waste management company in Muscat, Oman.

## Live preview

https://shahinalambd.github.io/ma-trading-website/

## Key features

- Home and detailed services pages
- Hero slideshow and filterable materials section
- Clients marquee with a seamless loop
- Sticky services sub-navigation that highlights the section in view
- Quote request form with client-side validation
- Scroll reveal animations and a fully responsive layout

## Tech used

- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts
- No build step, so the site runs as plain static files

## Run locally

Open `index.html` in a browser, or serve the folder with any static server.

## Notes

- All contact details are placeholders (`+000 0000 0000`, `hello@example.com`).
- Forms are static demos: they validate input but do not send any data.
